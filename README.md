# Live Voice Chat Translate

Real-time voice chat translation mod for Minecraft.

| Minecraft Version | Mod Loader |

| 26.1.2 | Fabric, NeoForge, Forge |

| 1.21.10 | Fabric, NeoForge, Forge |
| 1.21.8 | Fabric, NeoForge, Forge |
| 1.21.5 | Fabric, NeoForge, Forge |
| 1.21.4 | Fabric, NeoForge, Forge |
| 1.21.1 | Fabric, NeoForge, Forge, Quilt |
| 1.20.1 | Fabric, Forge, Quilt |

## Development

### Setup
1. Review the supported Minecraft versions in `settings.gradle.kts`.
2. Use `"Set active project to ..."` Gradle tasks to update the Minecraft version.
3. Use `buildAndCollect` Gradle task to store mod releases in `build/libs/`.
